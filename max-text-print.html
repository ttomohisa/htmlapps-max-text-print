使い方と注意事項

基本操作

  • 文字を入力すると、A4の安全領域に収まる最大文字サイズを自動計算します。
  • 「ページ分割」で、すべてを1ページにまとめるほか、空行ごと・1行ごと・1文字ごとに分けて一括印刷できます。各ページは個別に最大サイズへ調整されます。
  • 1ページにまとめる場合はEnterで入れた改行を維持し、長い行は用紙幅に合わせて自動で折り返します。
  • 「自動」の用紙向きでは全ページを縦・横の両方で評価し、印刷物全体として文字を大きくできる方へ統一します。
  • 書体は端末内のフォントから選べます。端末にない書体は近い書体へフォールバックします。
  • 印刷設定は入力文字と同様にこのブラウザへ自動保存されます。「印刷設定」の「初期値に戻す」で設定全体を既定値へ戻せます。
  • 詳細設定の「初期値に戻す」は、行間・文字間隔・縁取りだけを既定値へ戻します。どちらのリセットも直後のトーストから元に戻せます。
  • 「クリア」は直後のトーストから元に戻せます。文字の入力・貼り付け・日本語変換を始めると、新しい入力を保護するためクリアのUndoは終了します。
  • 複数ページ時はページ番号を入力して「移動」またはEnterで直接確認できます。1〜総ページ数の整数を指定してください。左右ボタン、または入力欄やヘルプを操作していないときの左右キーも使えます。「印刷する」では全ページをまとめて印刷します。
  • 一度に作成できるのは200ページまでです。再計算中や空入力・上限超過時は印刷できません。印刷画面が開く前に文字や印刷設定を変更した場合は、再計算後にもう一度「印刷する」を選んでください。PDFが必要な場合は、印刷先で「PDFに保存」を選んでください。

印刷時の注意

  • 印刷ダイアログの倍率や余白はブラウザ・OS・プリンター側の設定に影響されます。想定どおりでない場合は倍率100%を確認してください。
  • 余白0 mmはプリンターの印刷不能領域により端が欠けることがあります。通常は10 mmを推奨します。
  • 背景色を使う場合、ブラウザの「背景のグラフィック」等の設定を有効にする必要がある場合があります。
  • 書体は端末に入っているフォントを使います。同じ文章でも端末が変わると最適文字サイズが少し変わる場合があります。

プライバシー

入力文字と設定はこのブラウザ内だけで処理されます。外部サーバーへ送信しません。ブラウザでローカルストレージが利用できる場合、作業内容を同じブラウザ内へ自動保存します。

Basics

  • As you type, the app calculates the largest font size that still fits inside the A4 safe area.
  • Page splitting can keep everything on one page or create pages by blank line, line, or character. Each page is fitted independently.
  • In single-page mode, manual line breaks are preserved and long lines wrap automatically.
  • Auto orientation evaluates all pages in both portrait and landscape and uses one orientation for the whole print job.
  • You can choose from local typefaces. If a selected typeface is unavailable, the browser uses a similar local fallback.
  • Print settings are autosaved in this browser. “Reset to defaults” in Print settings restores all print settings.
  • Reset to defaults in Advanced settings restores only line height, letter spacing, and outline. Both resets can be undone from the toast immediately afterward.
  • Clear can be undone from its toast immediately afterward. Starting to type, paste, or compose text ends Clear Undo so it cannot replace your new input.
  • Enter a page number and choose Go or press Enter to jump directly. Use a whole number from 1 to the total page count. Previous/next buttons and arrow keys outside form fields (with Help closed) also work. Print sends all pages to the browser/OS print dialog in one job.
  • Up to 200 pages can be generated at once. Print is unavailable while recalculating, with empty text, or over the limit. If you edit text or print settings before the dialog opens, choose Print again after recalculation. Choose a PDF destination in the print dialog when you need a PDF.

Printing notes

  • Scale and margin behavior can still be affected by browser, OS, and printer settings. If output differs, check that scale is 100%.
  • A 0 mm margin can be clipped by printers that cannot print to the physical edge. 10 mm is recommended for normal use.
  • Colored backgrounds may require enabling “Background graphics” or a similar option in the print dialog.
  • The app uses fonts installed on the current device. The fitted size can vary slightly on another device.

Privacy

Text and settings are processed only in this browser and are not sent to an external server. When local storage is available, your work is autosaved in the same browser.
