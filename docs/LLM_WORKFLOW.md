# Coding-agent workflow

1. Read `AGENTS.md` and `APP_SPEC.md`.
2. Inspect `src/index.template.html` before changing behavior.
3. Keep changes focused and preserve the direct-print workflow.
4. Do not manually edit generated `dist/` files.
5. Run `scripts/check-repository.ps1` on Windows to rebuild and verify the release artifacts.
6. Test desktop, smartphone, Japanese, English, A4 portrait/landscape, printing, and direct local opening.
7. Update README, APP_SPEC, CHANGELOG, help text, and screenshots when behavior changes.
